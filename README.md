# 🧱 Tetris_UIT

> **Xếp gạch – phá hàng – phá kỷ lục!**
> Tựa game tuổi thơ quay trở lại với giao diện gọn gàng, dễ chơi. Chỉ cần vài phút là bạn sẽ bị cuốn vào đó... và không muốn dừng lại. 😎

Tetris_UIT là đồ án môn học "Kỹ năng nghề nghiệp" của nhóm Hidden Gem ở trường UIT. Nhóm làm theo kiểu *vibe coding*, vừa code vừa chơi thử, rồi từng người góp thêm một chút cho game hay hơn. Mục tiêu của tụi mình đơn giản thôi: làm ra một game Tetris **chơi vui, mượt, và dễ ghiền**.

---

## ✨ Có gì hay?

### 1. 🎮 Lối chơi Tetris kinh điển
Các khối gạch đủ hình dạng rơi từ trên xuống. Nhiệm vụ của bạn là xoay và sắp xếp chúng thật khéo để lấp đầy từng hàng ngang. Hàng nào đầy sẽ **biến mất**, nhường chỗ cho những khối tiếp theo. Để gạch chạm nóc là thua đó nha!

### 2. ⌨️ Điều khiển bằng bàn phím, nhanh và nhạy
Không cần chuột, chỉ cần vài phím quen thuộc là bạn đã có thể di chuyển, xoay và thả khối gạch trong tích tắc.

| Phím | Chức năng |
| :--: | --------- |
| ⬅️ ➡️ | Di chuyển sang trái / phải |
| ⬆️ | Xoay khối gạch |
| ⬇️ | Cho khối rơi nhanh hơn |
| `Space` | Thả khối xuống ngay lập tức |

### 3. 🏆 Tính điểm, săn kỷ lục
Mỗi hàng bạn phá đều được cộng điểm. Phá **nhiều hàng cùng lúc** thì điểm càng cao! Thử thách bản thân, rủ bạn bè cùng chơi và xem ai là "trùm xếp gạch" nhé.

### 4. 🔥 Càng chơi càng khó
Lúc đầu gạch rơi chậm để bạn làm quen. Nhưng đừng vội mừng, bạn càng lên level thì gạch rơi **càng nhanh**, đòi hỏi phản xạ và tính toán cực nhạy. Bạn trụ được đến level mấy?

## 🚀 Bắt đầu chơi

1. Tải project về máy:
   ```bash
   git clone <link-repo-cua-ban>
   cd tetris_game
   ```
2. Mở game và bắt đầu xếp gạch thôi! 🎉

---

## 💡 Mẹo nhỏ cho người mới

- Chừa sẵn **một cột trống** để chờ khối thẳng (khối I) rồi phá liền 4 hàng.
- Đừng xếp gạch quá cao ở giữa màn hình.
- Bình tĩnh: gạch rơi nhanh không đáng sợ bằng việc bạn luống cuống. 😄
